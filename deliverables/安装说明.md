# DeliverEat 安装与运行

`DeliverEat-android-arm64.apk` 为 Android ARM64 手机安装包，release 模式构建，约 33.2 MB。使用开发签名，供本地体验；正式上架需要配置发布签名及真实服务。

首次打开经过三步引导后，可以选择 **Explore as guest** 直接进入首页。也可使用本地演示登录，姓名非空、密码至少六位。演示验证码 `1234`，优惠码 `DELIVER10`。

47 个参考页面均可在 **Profile → About Us → Explore all screens** 中找到。商品、地址、收藏及本地订单等交互可以使用，支付不产生扣款。

完整源代码位于上级项目目录；架构与界面图片见 [项目说明](../README.md)，全部截图见 [界面图库](../docs/界面截图.md)。

此包面向 ARM64 真机。Android x86_64 模拟器可在源代码目录执行 `flutter run -d <device-id>` 运行对应架构版本。
